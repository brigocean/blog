# Blogy - блог на чистом PHP

Простой блог с категориями и статьями на PHP 8.1+, MySQL и шаблонизаторе Smarty без фреймворков.

## Стек

- PHP 8.1+ (PDO, строгая типизация, enum, readonly-свойства)
- MySQL 8 (оконные функции для выборки последних статей)
- Smarty 5 (автоэкранирование HTML включено)
- SCSS (компиляция через scssphp)
- Docker: nginx + php-fpm + mysql

## Функционал

- Главная: каждая категория, в которой есть статьи, с 3 последними постами по дате публикации и кнопкой "Все статьи".
- Страница категории: название, описание, список статей, сортировка по дате публикации и по просмотрам, пагинация.
- Страница статьи: изображение, название, описание, текст, категории, дата, счетчик просмотров и блок из 3 похожих статей.
- Сидер категорий и статей с генерацией текста и SVG-обложек.
- Страница 404 для несуществующих адресов, категорий, статей и страниц пагинации.

## Запуск в Docker

bash
docker compose up -d --build
docker compose exec php php bin/seed.php


Сайт будет доступен по адресу http://localhost:8081. Порт можно изменить переменной `APP_PORT`.

Схема БД применяется автоматически при первом старте контейнера MySQL. Повторно ее можно применить командой:

bash
docker compose exec php php bin/migrate.php


## Запуск без Docker

bash
composer install
export DB_HOST=127.0.0.1 DB_PORT=3306 DB_NAME=blog DB_USER=root DB_PASSWORD=secret
php bin/migrate.php
php bin/seed.php
php -S localhost:8000 -t public public/index.php


## Сидер

bash
php bin/seed.php --categories=6 --posts=60


Сидер очищает таблицы и заново заполняет их: создает категории, статьи со случайной датой публикации за последний год, случайным числом просмотров и 1-3 категориями, а также SVG-обложки в `public/uploads/posts`.

## Стили

Исходники лежат в `scss/`, собранный файл - `public/assets/css/app.css`. Пересборка:

bash
composer build-css


## Структура проекта
bin/                    консольные скрипты: migrate, seed, build-css
config/config.php       настройки из переменных окружения
database/schema.sql     схема БД
docker/                 конфигурация nginx и php-fpm
public/                 корень веб-сервера: index.php, стили, загрузки
scss/                   исходники стилей
src/Core/               Database, Router, View, Paginator, NotFoundException
src/Controller/         контроллеры главной, категории и статьи
src/Repository/         SQL-запросы к категориям и статьям, enum сортировки
src/Seeder/             сидер, генератор текста, генератор slug
templates/              шаблоны Smarty


## Структура данных

- `categories` - категории: название, slug, описание.
- `posts` - статьи: изображение, название, slug, описание, текст, просмотры, дата публикации.
- `category_post` - связь многие-ко-многим, статья может относиться к одной или нескольким категориям.

Индексы добавлены на `published_at` и `views` для сортировок, на `post_id` в связующей таблице для обратных выборок.

## Решения

- Front controller `public/index.php` собирает зависимости и передает запрос в простой роутер на регулярных выражениях.
- Контроллеры тонкие: получают данные из репозиториев и передают их в шаблон.
- Все SQL-запросы находятся в репозиториях и используют подготовленные выражения. Поле сортировки не подставляется из запроса напрямую, а выбирается через enum `PostSort`.
- Главная страница строится одним запросом: `ROW_NUMBER() OVER (PARTITION BY category_id ORDER BY published_at DESC)` отбирает по 3 последних статьи в каждой категории, категории без статей в выборку не попадают.
- Похожие статьи - статьи с наибольшим числом общих категорий, при равенстве выше более свежие.
- Просмотры увеличиваются атомарным `UPDATE posts SET views = views + 1`.
